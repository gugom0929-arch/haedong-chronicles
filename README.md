# 해동신이록 설정집 · Haedong Chronicles

《해동신이록》은 한국 설화를 바탕으로 만든 창작 판타지 세계관입니다. 이 설정집에는 《청명(靑冥)의 시대》의 인물, 세력, 주요 사건을 담았습니다.

하늘의 질서를 내세우는 천휘국은 대가 없이 날 수 있는 아이 우투리의 존재를 두려워합니다. 그로 인해 벌어진 숙청으로 가족을 잃은 묵신우는 복수를 좇다가 자신이 저지른 일과 마주합니다.
